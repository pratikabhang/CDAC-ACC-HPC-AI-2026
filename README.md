## 1. Introduction

This repository contains subject-wise study material, programming exercises, practical implementations, and reference resources related to the **Advanced Certificate Course (ACC) in High Performance Computing (HPC) and Artificial Intelligence (AI), 2026**.

The repository is organized to support systematic learning, practical implementation, concept revision, and technical preparation across programming, operating systems, networking, cloud computing, parallel programming, and high-performance computing.

The documentation follows a structured academic approach inspired by university-style study repositories, with an emphasis on clarity, organization, and hands-on learning.

## 2. Objectives

- Develop a strong foundation in C, C++, and Python programming.
- Understand fundamental data structures and algorithms.
- Learn Linux commands, operating system concepts, and system administration fundamentals.
- Understand computer networking and communication protocols.
- Explore cloud computing and virtualization concepts.
- Practise parallel programming using C++ and Python.
- Understand the principles and architecture of high-performance computing systems.
- Explore advanced HPC concepts, performance optimization, and scalable computing.
- Maintain a centralized reference for practical work, revision, and self-study.

## 4. Subject Overview

### 4.1 C Programming & Data Structures

Core programming concepts and data organization techniques.

Topics for study:
- Variables, data types, operators, and control statements
- Functions, arrays, pointers, and strings
- Structures, unions, and dynamic memory allocation
- Linked lists, stacks, queues, trees, and searching
- Sorting algorithms and algorithmic complexity

### 4.2 C++ Programming

Object-oriented programming and efficient software development using C++.

Topics for study:
- Classes, objects, constructors, and destructors
- Inheritance, polymorphism, and encapsulation
- Function and operator overloading
- Pointers, references, and memory management
- Standard Template Library (STL)

### 4.3 C++ Parallel Programming

Parallel execution concepts and performance-oriented programming.

Topics for study:
- Processes, threads, and concurrency
- Parallel execution and task decomposition
- Synchronization and shared-memory programming
- Race conditions and thread safety
- Parallel performance measurement and optimization

### 4.4 Python Programming

Python fundamentals for general-purpose programming and computational tasks.

Topics for study:
- Data types, operators, and control flow
- Lists, tuples, dictionaries, and sets
- Functions, modules, and packages
- File handling and exception handling
- Object-oriented programming and commonly used libraries

### 4.5 Python Parallel Programming

Techniques for concurrent and parallel execution in Python.

Topics for study:
- Iterative, concurrent, and parallel execution
- Threading and multiprocessing
- Process pools and task distribution
- Inter-process communication
- Performance analysis and workload management

### 4.6 Linux & Operating Systems

Fundamental operating system concepts and practical Linux usage.

Topics for study:
- Linux commands, shell scripting, and file permissions
- Processes, threads, and scheduling
- Memory management and virtual memory
- File systems and system calls
- Synchronization and inter-process communication

### 4.7 Computer Networks & Internet

Networking concepts required for distributed and network-based computing.

Topics for study:
- OSI and TCP/IP models
- IP addressing and subnetting
- TCP, UDP, DNS, HTTP, and related protocols
- Network devices, routing, and switching
- Client-server communication and sockets

### 4.8 Cloud Computing & Operating Systems

Concepts related to cloud infrastructure and computing environments.

Topics for study:
- Cloud service and deployment models
- Virtualization and virtual machines
- Resource allocation and management
- Operating system fundamentals in cloud environments
- Scalability, availability, and distributed resources

### 4.9 High Performance Computing (HPC)

Fundamentals of high-performance systems and parallel computation.

Topics for study:
- HPC architecture and computing clusters
- Parallel and distributed computing
- Workload decomposition and scheduling
- Performance metrics, speedup, and efficiency
- Scalability, load balancing, and bottleneck analysis

### 4.10 Advanced High Performance Computing

Advanced concepts used to improve the performance and scalability of computational workloads.

Topics for study:
- Advanced parallel computing techniques
- Distributed execution and communication overhead
- HPC performance profiling and optimization
- Parallel workload scaling and resource utilization
- Scientific computing and large-scale computational applications

*Note: Topic lists are indicative study areas, not a verified official syllabus. Refer to the relevant subject directories and course materials for the actual content covered.*

## 6. Recommended Study Methodology

1. **Understand:** Review the fundamental concepts of each subject.
2. **Practise:** Execute relevant programs and complete exercises.
3. **Analyze:** Study the output, algorithm, and implementation details.
4. **Optimize:** For parallel and HPC programs, examine performance and resource utilization.
5. **Revise:** Maintain concise notes, important commands, and key concepts.
6. **Apply:** Use the concepts to solve computational and programming problems.

## 7. Learning Outcomes

On completing the relevant study and practical exercises, learners should be better prepared to:

- Write programs using C, C++, and Python.
- Apply appropriate data structures and algorithms.
