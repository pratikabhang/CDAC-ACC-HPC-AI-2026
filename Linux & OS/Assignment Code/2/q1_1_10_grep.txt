Using grep

1)  Display all employees who work in the IT department. grep “IT” employees.txt

------------------------------------------------------------------------

2)  Display all employees located in Pune. grep “Pune” employees.txt

------------------------------------------------------------------------

3)  Display all employees whose name starts with the letter ‘A’. grep -E ‘[1]+ A’ employees.txt

------------------------------------------------------------------------

4)  Find all employees whose salary contains the digit ‘7’. grep -E ‘[0-9]7[0-9]$’ employees.txt

------------------------------------------------------------------------

5)  Display line numbers along with all HR employees. grep -n “HR” employees.txt

------------------------------------------------------------------------

6)  Count how many employees belong to the Finance department. grep -c “Finance” employees.txt

------------------------------------------------------------------------

7)  Display all employees except those from the Sales department. grep -v “Sales” employees.txt

------------------------------------------------------------------------

8)  Display only the names of employees working in Mumbai. grep “Mumbai” employees.txt awk ‘{print $2}’

------------------------------------------------------------------------

9)  Display all employees whose salary is 60000 or above. grep -E ‘(6[0-9]{4}|[7-9][0-9]{4}|[1-9][0-9]{5,})$’ employees.txt

------------------------------------------------------------------------

    letters. grep -iw “IT” employees.txt
